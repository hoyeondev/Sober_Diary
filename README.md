### ✨ 주요 기능

- 캘린더 — 월별 음주·금주 현황을 색상으로 한눈에 확인
- 일기 기록 — 날짜별 음주 여부, 주종, 메모 입력
- 연속 금주 스트릭 — 현재 몇 일째 금주 중인지 표시
- 월별 요약 — 월간 금주·음주 일수 통계 및 진행 바
- 색상 커스터마이징 — 음주·금주 색상을 프리셋 또는 컬러피커로 직접 설정
- 매일 알림 — 오후 3시 응원 알림 (켬/끔 설정 가능)
